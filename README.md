Entry for the make.fun bounty [How Many Tabs Do You Have Open?](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d)

## The entry

One number, digits only: **1**.

One tab open. One thing at a time — everything else closed, read, or
saved for later. The most surprising honest count in a field full of
triple-digit hoards is the smallest possible real one.

## How it works

`main.py` writes the count as a single digit to `/output/entry.txt`,
with a self-check that the output is 1–5 characters of digits only,
matching the bounty gate.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
